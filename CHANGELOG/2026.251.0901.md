# 2026.251.0901 — fix(dispatcher): actions: write for the cancel-in-progress dedupe

## Summary

The installed pr-validator dispatcher (`.github/workflows/pr-validator.yml`) already carries `actions: write` on base (main). This PR appends the inline comment `# REQUIRED for the concurrency cancel-in-progress dedupe` to that permission line, documenting at the point of use why the dispatcher — not the reusable — must hold `actions: write`.

Context: the #163 dispatch-expansion regression (measured 0-job instant failures on opencharly — runs 34202345354, 34203066358, 34203146946) was root-caused to the REUSABLE pr-validator workflow carrying `cancel-in-progress` concurrency, which requires the caller to hold `actions: write`; legacy callers lacking it failed to expand. opencharly/.github#85 moved the dedupe to the per-repo dispatchers and keeps the reusable caller-compatible. This comment records the requirement at the only place it must hold.
